# Toolloom

**Weave any library into AI-ready tools.**

Toolloom is a VS Code extension that enables developers to convert existing libraries (npm packages and Python libraries) into Model Context Protocol (MCP) servers, making their functions directly accessible to AI agents.

## Initial Commands
- `Toolloom: Convert Package to MCP` (`toolloom.start`): Prompts for an npm package name to convert.

## Development
1. Install dependencies:
   ```bash
   npm install
   ```
2. Build the extension:
   ```bash
   npm run compile
   ```
3. Press `F5` in VS Code to launch the Extension Development Host window.
